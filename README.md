# I Choicefood

Create a brand-new web application called I-ChoiceFood 2.0.



PROJECT CONCEPT:

I-ChoiceFood 2.0 is a Filipino Recipe Book and Food Costing Management System. It helps users discover Filipino recipes, calculate ingredient expenses, adjust serving portions, and learn how to prepare different dishes.



DESIGN:

Create a beautiful, modern, responsive website with a warm Filipino kitchen aesthetic.



Color palette:



- Warm cream: #F6EBDD

- Olive green: #687B50

- Terracotta: #BD754D

- Soft white: #FFFFFF

- Dark brown: #40382F



Use beautiful Filipino food photography, rounded cards, clean typography, subtle animations, and comfortable spacing.



HOMEPAGE:

Include:



- I-ChoiceFood 2.0 logo and navigation.

- A welcoming hero section introducing the recipe platform.

- A recipe search bar.

- Featured Filipino dishes.

- Popular recipes.

- Food category cards.

- A short introduction to the system.



NAVIGATION:



1. Home

2. Recipe Book

3. Categories

4. Cost Calculator

5. Cooking Simulator

6. My Recipes

7. Favorites



DESIGN REQUIREMENTS:



- Make the interface responsive for desktop, tablet, and mobile.

- Use reusable components.

- Use realistic Filipino recipe examples such as Adobo, Sinigang, Tinola, Kare-Kare, and Pinakbet.

- Use sample data for now.

- Make navigation and interface interactions functional where possible.

- Do not create restaurant location features, maps, or restaurant directories.

- Do not integrate Supabase yet.

- Do not implement fake authentication or pretend to save data permanently.



IMPORTANT:

Build the frontend foundation first. Keep the code organized and prepare the architecture for future database integration.



This is Phase 1 of a larger project. Do not attempt to implement all future features at once.
